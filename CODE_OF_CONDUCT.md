# Code of conduct

We want this project to be a welcoming place to collaborate on a practical, often tedious subject.

## Our standards

- Be respectful and assume good faith. Disagree about the data or the design, not about the person.
- Give and accept constructive feedback; credit others' work.
- No harassment, discrimination, personal attacks, or publication of others' private information.
- Keep discussion on topic; do not use project spaces for promotion unrelated to the project.

## Enforcement

Maintainers may edit or remove comments, lock threads, or block contributors who violate these standards. Report
concerns privately to the maintainers through GitHub (Security → Report a vulnerability, or a direct message to a
maintainer). All reports are handled confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
